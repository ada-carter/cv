# Computer Vision Across the Marine Sciences

Welcome to this open curriculum on applying computer vision and vision-language models to marine science research and monitoring.

This book is organized into four chapters and a set of appendices:

**Preface:** Tools, acknowledgements, and student projects.

**Chapter 1 - Introduction to Marine Imaging:** An overview of underwater and aerial imaging systems, image types encountered in marine research, and the fundamentals of AI applied to marine imagery.

**Chapter 2 - Introduction to Computer Vision:** Annotation workflows, data augmentation techniques, and core evaluation metrics for marine CV pipelines.

**Chapter 3 - Computer Vision Development:** Hands-on lessons covering classification, object detection (YOLO, Faster R-CNN, RetinaNet), instance segmentation, keypoint detection, GANs, super-resolution, model interpretability, edge deployment, and live inference.

**Chapter 4 - Synthesis Project:** Assembling a complete marine CV project: dataset selection, model card creation, Hugging Face organization setup, and deployment via Streamlit and Gradio.

**Appendices:** Bibliography, survey instruments, and supplementary lessons.

Use the sidebar to navigate between lessons. All notebooks include a Colab launch badge so you can run them directly in Google Colab without any local setup.
